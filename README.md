# GreenProductive



## 📌 About GreenProductive

![Design Preview](https://github.com/user-attachments/assets/068c0acd-9125-4e1a-91a8-d8201a9135ca)


GreenProductive is a modern and interactive **To-Do List application** designed to boost productivity and help users stay on top of their daily tasks.  
With its clean, custom-designed interface and real-time updates, the app makes task management simple and enjoyable.  

✅ Add and organize tasks effortlessly.  
✅ Track progress visually with an auto-updating progress bar.  
✅ Mark tasks as completed with a single click.  
✅ Get an instant **Daily Achievement Score** to reflect your productivity.  

Whether for students, professionals, or anyone who wants to stay organized, **GreenProductive** makes managing tasks more effective and motivating.

## 🛠 Installation

First, clone the repository and navigate to the project folder:

```bash
git clone https://github.com/haninotarek/GreenProductive.git
cd GreenProductive
npm install
npm start
```
